# App 介面與架構遷移評估

**閱讀定位：本文保留遷移時的設計背景，不是全部已完成的功能清單。**
目前實作的逐層解說、程式呼叫路線、資料安全與學習練習，請先看 [完整開發指南](development-guide.md)；
每個檔案的用途與 2026-10-03 清理結果見 [檔案索引](file-inventory.md)。

## 遷移前的狀況（歷史背景）

- 遷移前的 `gui.py` 把表單轉換、Tk 元件、背景執行、排程、錯誤提示與檔案操作放在一起，難以獨立調整產品介面。
- `AutomationRunner`、瀏覽器傳輸、OCR 與紀錄管理已有分離，可保留既有測試及訂位流程。
- GUI 使用背景執行緒與 queue，但還依靠全域 `redirect_stdout` 收集文字；新介面應使用明確的狀態事件。
- 設定與紀錄預設依工作目錄定位，尚不適合從桌面捷徑或安裝目錄啟動。
- `setup.py` 有 GUI 入口，尚無桌面安裝包、模型資源收集與乾淨機器的安裝驗證流程。執行期依賴也混有開發工具。

## 選型依據（已採用 Qt，其他方案為評估）

若以 Windows 桌面 App 為首要目標，優先評估 **PySide6 + Qt Quick/QML**：
QML 負責視覺與互動，Python 保留訂票服務。以一致的元件、排版及狀態設計建立產品感，
不是換上框架就自動得到完成的產品。

React + Tauri 也能製作桌面介面，並可封裝 Python sidecar，但會增加前端、Rust 外殼、
Python 子程序之間的通訊及部署工作；目前專案為 Python 核心，初期不優先增加此複雜度。
若目標是手機，需另行規劃任務實際在哪個裝置執行，不能假設桌面 Chrome 自動化可直接移植。

## 建議分層

```text
QML 頁面／共用視覺元件
        ↓ 操作指令      ↑ 結構化狀態
桌面 Controller／ViewModel
        ↓
應用服務：設定、任務啟停、訂位紀錄核對與封存
        ↓
既有 AutomationRunner／BrowserRequest／CaptchaReader
        ↓
本機設定、結果、事件與防重送紀錄
```

- UI 不直接發起網路請求，不自行判定訂位成功，也不直接刪除狀態檔。
- 應用服務不依賴 Tk 或 QML；CLI 與新版 GUI 共用相同的業務規則。
- 背景 worker 負責瀏覽器與 OCR 的生命週期；主執行緒只更新畫面。
- 明確區分待命、排程等待、查詢中、送出中、成功、待確認、停止及失敗。
- 停止屬於合作式停止；送出訂位後不得因介面關閉或失去回應而自動重新送出。
- 保留現有跨程序鎖、原子存檔、待確認阻擋及人工核對後封存。

## 介面方向（包含尚未完成的目標）

採用固定側欄與清晰主內容區，建立統一的字級、間距、圓角、圖示、狀態色及鍵盤焦點。

| 頁面 | 主要內容與操作 |
| --- | --- |
| 總覽 | 下一筆行程、目前任務狀態、最近訂位、繼續設定 |
| 新增行程 | 起訖站與日期、時段與票數；進階重試設定收合；固定行程摘要與啟動操作 |
| 任務進度 | 倒數、目前階段、查詢次數、符合車次、停止；詳細日誌次要呈現 |
| 我的訂位 | 票卡／列表、狀態篩選、明細側欄、移至歷史與待確認核對 |
| 設定 | 常用乘客、設定匯入匯出、環境檢查、資料位置與版本資訊 |

保留眼睛切換遮蔽功能。錯誤優先就地提示，成功使用輕量通知；只有重要確認才開對話框。
訂位成功頁必須呈現代碼與付款期限。本機封存和官網取消的含義保持明確。

## 安裝與資料

- 預設資料存放使用者的 App 資料目錄，與唯讀的程式資源分開。
- 支援匯入舊設定及其關聯 state/runs；不得只複製設定而遺漏防重送狀態。
- 打包 Python、Qt/QML、OCR 模型及必要執行庫；Chrome 採已安裝瀏覽器並提供環境檢查。
- 先製作可重現的資料夾式發行包，再製作安裝程式；檢查升級後設定與紀錄仍保留。
- 正式發行前核對第三方資源與套件授權、版本資訊及安裝／解除安裝行為。

## 遷移順序與驗收

1. 確認目標平台，抽離應用服務與事件介面，保持既有 CLI/Tk 測試可用。
2. 建立新版可操作的介面樣板，以模擬資料驗收主要頁面、縮放與鍵盤操作。
3. 接上設定、任務與紀錄服務，逐項驗證真實功能；保留舊 GUI 作為過渡入口。
4. 在乾淨 Windows 環境驗證安裝包、模型載入、缺少 Chrome 的提示與升級資料保留。

完成標準包含 100%／125%／150% 顯示縮放、不需命令列完成日常操作、
送出後斷線不重送、UI 關閉時 worker 正確清理，以及舊資料匯入後仍保有防重送保護。
