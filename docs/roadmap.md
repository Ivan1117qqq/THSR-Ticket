## 現況判斷

目前已具備 Qt 桌面介面、設定保存、排程查票、自動訂位、查票暫時斷線重試、防重送、結果封存、人工核對與取消引導，以及未簽章 Windows 安裝包。原始碼亦已完成紀錄管理與中斷復原、背景訂位歷史、逐列勾選、掃描容錯、歷史診斷及可選桌面通知；接下來優先補上新版打包與通知人工驗收。歷史診斷已限制單檔讀取量；大型事件檔的效能與完整 UI 幀率仍待量測。

取消引導仍須在官網完成取消；本機封存不取消票。任務摘要只協助重開程式後理解狀態，不會恢復工作，也不是跨程序即時監控。已存在的訂位狀態檔仍優先阻擋再次送出。

## 需要另行定義範圍的功能

- **程式直接取消官網訂位**：目前沒有實作。需先釐清查詢、取消確認、結果未知與人工復原流程；不可把本機移除紀錄當成官網取消成功。任何真實取消都需由使用者確認特定訂位。
- **來回票、會員及其他證件**：涉及設定模型、網站表單、結果解析與所有操作介面；不能只增加幾個 UI 欄位。
- **多行程並行**：先完成任務協調與防重複策略，否則不同設定仍可能送出重複需求。
- **外部通知與常駐模式**：本機桌面通知已完成原始碼實作，預設關閉，仍待 Windows 真實呈現與點擊喚回驗收；郵件、通訊服務與關閉視窗後常駐須另行設計。
