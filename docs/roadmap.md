# 後續優化與驗收計畫

更新日期：2026-10-22；版本標示 0.3.3。歷史紀錄背景管理、錯誤分類及中斷復原已完成原始碼實作，尚未更新既有安裝包。既有 EXE 自我檢查及不同 AppId 的隔離安裝／覆裝／解除安裝測試通過；正式 AppId 的乾淨 Windows 與官網驗收仍待完成。此次沒有更動訂位行為，也沒有操作真實訂位。

已完成的第一階段：push／PR 的 Windows Qt 回歸、`--require-desktop` 必測檢查與 JUnit 報告保存。最新本機 299 項通過、11 項選用測試跳過；版本與隔離驗收的範圍見 [驗證紀錄](verification.md)。

## 現況判斷

目前已具備 Qt 桌面介面、設定保存、排程查票、自動訂位、查票暫時斷線重試、防重送、結果封存、人工核對與取消引導，以及未簽章 Windows 安裝包。原始碼亦已完成紀錄管理與中斷復原；接下來優先補上新版交付驗收、歷史診斷及大量資料效能量測。

取消引導仍須在官網完成取消；本機封存不取消票。任務摘要只協助重開程式後理解狀態，不會恢復工作，也不是跨程序即時監控。已存在的訂位狀態檔仍優先阻擋再次送出。

## 需要另行定義範圍的功能

- **程式直接取消官網訂位**：目前沒有實作。需先釐清查詢、取消確認、結果未知與人工復原流程；不可把本機移除紀錄當成官網取消成功。任何真實取消都需由使用者確認特定訂位。
- **來回票、會員及其他證件**：涉及設定模型、網站表單、結果解析與所有操作介面；不能只增加幾個 UI 欄位。
- **多行程並行**：先完成任務協調與防重複策略，否則不同設定仍可能送出重複需求。
- **任務完成通知**：可先設計本機桌面通知；郵件或通訊服務另涉及憑證儲存、收件對象與發送授權。
