# 圖形設定介面

此頁介紹舊版 Tk 介面。新版商用風格 Qt 桌面介面與 Windows 打包方式請見 [Travel Desk](desktop.md)。

在專案資料夾執行：

```powershell
.\.venv\windows\Scripts\python.exe -m thsr_ticket.gui
```

此指令使用目前工作區已有的環境。新建環境若位於 `.venv/Scripts`，請替換 Python 路徑。
需安裝 README 的自動化套件與 Chrome，並使用含 Tkinter 的 Python。此次本機確認 Tk 8.6 可用。
重新安裝專案後亦提供 `thsr-ticket-gui` 啟動入口。

## 第一次使用

介面採淺色卡片與雙欄設定，分成「訂票設定」「執行進度」「訂位紀錄」三頁。
設定按行程、啟動與重試、票種、訂票人資料分組。頂端的「立即開始」只把啟動時間設為現在，
不會立即送出查詢；「交換起訖站」可交換站點，仍需自行確認行程。

1. 按「載入設定」，選擇 `booking.local.json`。視窗不會自動讀取個資檔案。
2. 核對行程、票數及乘客資料。身分證欄位以星號顯示，手機仍可見。
   身分證欄位旁的眼睛按鈕可切換「顯示／隱藏」，不會更動內容；載入設定時會恢復遮蔽。
3. 如需單獨檢查格式，選「更多 → 檢查設定」，不連線、不訂位。啟動時也會自動檢查。
4. 先按「只查票」測試。已載入個人設定時直接保存回原檔；新設定或範本第一次儲存才詢問位置。
5. 要正式訂位時按「自動訂位（不付款）」；這個按鈕會啟動可送出訂位的流程，取得訂位代碼後停止。

也可直接填寫空白表單，再儲存成 `booking.local.json`。不要選擇共用範本、狀態檔或結果檔來保存個資設定。

「儲存設定」保存至目前檔案；「另存設定」讓你選另一個檔案，成功後以新檔案作為目前設定。
取消另存不會變更目前檔案或啟動訂票。按「只查票」或「自動訂位」會先驗證及保存畫面上的內容，
儲存失敗就不啟動；正常情況會沿用原檔對應的訂位紀錄與防重送機制。
設定仍為明文 JSON；若使用自訂檔名，請將該檔加入 Git 忽略規則。
欄位意義詳見 [設定指南](automation.md#設定欄位)。

## 時間與執行

- 開始查票時間使用台灣時區，格式為 `YYYY-MM-DD HH:MM:SS`。載入帶其他時區的時間會轉成台灣時間顯示。
- 日期旁的「日曆」可直接選日期；啟動日期變更時保留時間。票數可使用上下箭頭調整。
- 搭車日期與查票啟動時間是不同欄位。啟動時間已過會立即查詢，設定的日期是否已開賣仍由網站判定。
- 車次欄位可填 `615, 617`，也接受中文逗號；留空表示不指定車次，仍需符合時間範圍。
- 執行時預載 OCR 與 Chrome，再等待啟動時間。所有網路操作在背景執行，視窗可繼續顯示進度。
- 執行中不可修改設定或同時啟動第二筆；完成或停止後才解鎖。畫面保留本次及先前的輸出。
- 進度頁以狀態標題、查詢輪數與活動指示條顯示執行狀態；指示條不代表訂位成功比例。「顯示詳細紀錄」才會展開文字輸出。
- 設定頁右側提供捲動條與滑鼠滾輪操作，較小視窗也能存取下方欄位。
- 原本的次數上限、驗證碼重試、執行紀錄及防重複訂位機制保持有效。

## 停止與關閉

「停止」會立即取消排程或重試等待，並阻止後續網路操作；正在執行的請求需要先回傳或逾時。
若最終訂位已送出，程式會等待並處理回應，不會取消已成立的訂位，也不會因停止而自動重送。
關閉視窗時若仍在執行，會先要求停止，完成清理後才關閉。

## 在視窗內管理訂位

載入設定後，「訂位紀錄」頁以表格顯示目前訂位。選取後可看到座位、金額、繳費期限與票數。
勾選「包含歷史紀錄」可查看已移出的紀錄，執行完成時也會重新整理。
也可按「重新整理紀錄」手動更新。資料來自本機檔案，不會同步官網付款或取消狀態。

若按自動訂位遇到既有 `.state.json`，視窗會直接切換到訂位紀錄頁，本次不啟動訂票。
確定準備下一筆時：

1. 閱讀原訂位結果，確認是否仍需要原票。
2. 選取目前訂位，按「移至歷史」，確認對話框中的代碼即可，不必重新輸入。
3. 封存成功後回到訂票設定，修改行程，再自行啟動。原官網訂位不會因此取消。

若送出訂位後斷線，出現「結果待確認」：

1. 選取該筆，按「處理待確認」，使用對話框中的按鈕開啟官網核對。
2. 選擇已訂位、確認沒有成立訂位，或已自行取消。已訂位需填入官網代碼。
3. 勾選已核對，再按「確認並移至歷史」。尚不確定請按「返回」。

此流程只記錄你的核對結果，不會自動判定官網狀態，也不會取消原票。
原始狀態檔完整保存於封存目錄，另存 `resolution.json` 核對紀錄。
取消、未勾選確認、紀錄已變更或移動失敗時，原防重送狀態仍保留。損壞或未知狀態不提供直接清除。
執行中會停用紀錄管理操作，避免一邊訂位一邊封存。
「開啟紀錄資料夾」在 Windows 檔案總管中開啟本機紀錄目錄，方便查看 JSON 與執行紀錄。
進階使用者仍可使用 [紀錄管理指令](automation.md#查看封存與準備下一筆)。

## 驗證範圍

離線測試涵蓋設定儲存、啟動模式、停止、封存取消、待確認核對、原始紀錄保留、狀態變更與操作互斥。
2026-10-02：174 項通過、11 項選用測試跳過，Flake8 通過。
隱藏 Tk 視窗測試只使用測試資料；沒有載入個人設定或操作真實訂位。
尚未完成新版使用者實際操作的畫面驗收或圖形模式實站訂位測試。

## 按鈕配置

| 位置 | 操作 |
| --- | --- |
| 頂端 | 載入、儲存、另存；低頻檢查與資料夾入口收在「更多」 |
| 設定頁 | 日曆、交換起訖站、立即開始（只設定啟動時間） |
| 底部 | 只查票、自動訂位；執行期間才顯示停止 |
| 訂位紀錄 | 依選取狀態啟用移至歷史或處理待確認；另有重新整理、官網與資料夾入口 |

一般操作不需編輯 JSON 或輸入命令；官網結果核對仍需本人操作。
